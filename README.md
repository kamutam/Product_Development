# Brihaspathi Technologies - Product Development & Automated Compliance Engine

Enterprise web application for **Brihaspathi Technologies®** (*"The Guru of Tomorrow's Technology"*), built for automated spec evaluation, STQC & ARAI compliance tracking, OEM partner vendor management, and visual brochure catalog showcase.

---

## 🌟 Key Features

1. **Visual Catalog Showcase & Brochure Series**:
   - Brochure-inspired series banners: **12MP DEEPIN VIEW SERIES**, **COLORVU 24/7 FULL COLOR NIGHT VISION**, **180° DUAL LENS PANORAMA**, **STQC GOVT LAB CERTIFIED SURVEILLANCE**, and **AUTONOMOUS SERVICE ROBOTICS**.
   - 1-Click camera product photos linking directly to official manufacturer PDF datasheets.

2. **STQC & ARAI Compliance Vault**:
   - Master Annexure-A directory for 52+ STQC Lab-certified CP Plus models and ARAI AIS-140 automotive mobile CCTV units.
   - Verified ONVIF protocol compliance: `ONVIF (Profile S, Profile G, Profile T)` for standard IP cameras.

3. **Master OEM Vendor Directory**:
   - Deeply integrated database of **53 OEM partner companies** across India, USA, Taiwan, China, South Korea, Singapore, Germany, France, Denmark, and Israel.
   - Filter by **Solutions** (Robotics, CCTV, Drones, Wildlife PIDS, Interlock, Displays), Country, and City.

4. **1-Click Google Spreadsheet Live Sync**:
   - Live CSV/Google Sheet import for dynamic catalog expansion and spec auto-extraction.

---

## 🚀 Tech Stack

- **Frontend**: React, Vite
- **Styling**: Modern Vanilla CSS, Glassmorphism, Dark UI Design System
- **Icons**: Lucide React
- **Asset Pipeline**: Studio Photography Renders & Vector Assets

## 🛠️ Getting Started

```bash
# Clone the repository
git clone https://github.com/kamutam/Product_Development.git

# Navigate to directory
cd Product_Development

# Install dependencies
npm install

# Run dev server
npm run dev

# Build production bundle
npm run build
```
